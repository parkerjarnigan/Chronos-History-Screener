# Historical Cartoons & Maps Directory

Drop your image files into this directory (`/public/images/cartoons/`) to display original historical political cartoons and maps in the quiz.

### Supported Question Mappings:

1. **French Revolution Three Estates (1789)**
   - Question ID: `u1-t3-cartoon-estates`
   - Default Path: `/images/cartoons/estates_cartoon.png` (or `.jpg`)
   - Subject: The 1789 French cartoon *"A faut esperer q'eu jeu la finira bentot"* showing the 3rd Estate peasant carrying the clergy and nobility.

2. **Europe 1914 Central Powers Geography Map**
   - Question ID: `u3-t2-central-powers-geography`
   - Default Path: `/images/cartoons/central_powers_map.png` (or `.jpg`)
   - Subject: 1914 map of Europe showing Central Powers surrounded by Allied Western Front and Eastern Front.

3. **WWI "Chain of Friendship" Cartoon (July 1914)**
   - Question ID: `u3-t3-chain-friendship-cartoon`
   - Default Path: `/images/cartoons/chain_alliances.png` (or `.jpg`)
   - Subject: The American cartoon showing the domino chain of European powers threatening each other ("If you hit him, I'll...").

4. **Appeasement "Spineless Leaders of Democracy" (1938)**
   - Question ID: `u4-t3-appeasement-cartoon`
   - Default Path: `/images/cartoons/appeasement_cartoon.png` (or `.jpg`)
   - Subject: David Low's 1938 cartoon showing Hitler marching across the bent-over backs of democratic leaders.

*Note: If an image file is not present or cannot be loaded, the app automatically falls back to an accessible, color-coded historical vector diagram.*
